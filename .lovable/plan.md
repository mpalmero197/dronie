

# Mission Summary PDF Report

## Approach

Add an "Export PDF" button to the FlightPlanner sidebar that generates a professional mission summary report using **jsPDF** (already available or easily added) and **html2canvas** (already in the project) for the map screenshot.

## Report Contents

1. **Header**: "Mission Summary Report" with project name, date, drone model
2. **Map Screenshot**: Captured from the current map view using html2canvas
3. **Flight Statistics Table**: Area, altitude, GSD, waypoints, distance, flight time, batteries needed, overlap, pattern, terrain-following status, min/max elevation if terrain data exists
4. **Waypoint Table**: First ~50 waypoints with WP#, Lat, Lng, Altitude (paginated if needed)
5. **Footer**: Generated by Dronie, timestamp

## Implementation

### 1. Install jsPDF

Add `jspdf` dependency.

### 2. New utility: `src/lib/generateMissionPDF.ts`

A standalone function that accepts:
- `stats` object (from FlightPlanner)
- `params` (FlightParams)
- `waypoints` array
- `mapScreenshot` (base64 image from html2canvas)
- `projectName`, `droneName`, `terrainData`
- `perWpAltitudes`

Generates the PDF with:
- Title + metadata header
- Embedded map screenshot (scaled to fit page width)
- Stats summary as a formatted table
- Waypoint table with columns: WP#, Lat, Lng, Alt (m)
- Returns a Blob for download

### 3. Update `FlightPlanner.tsx`

- Add a `FileText` (or `FileDown`) icon button next to existing KML/CSV download buttons
- On click: capture map screenshot via `html2canvas`, call `generateMissionPDF`, trigger download
- Show a loading toast while generating

### 4. Update `MapViewer.tsx`

- Pass `mapContainerRef` to FlightPlanner so it can capture the map screenshot
